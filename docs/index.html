ProconChat Jacareí — Chatbot para Orientação ao Consumidor via WhatsApp

6DSM – 2º Sem. 2026 • Em desenvolvimento

Projeto acadêmico (6DSM – 2º Sem. 2026) em parceria com a Fundação PROCON Jacareí para desenvolvimento de um chatbot inteligente integrado à WhatsApp Business Cloud API. Orienta cidadãos sobre direitos do consumidor, procedimentos de reclamação, prazos e documentos via fluxos estruturados e LLM, permitindo também agendamento presencial e painel de gestão.

Minha participação: Atuação no desenvolvimento da solução: arquitetura e estruturação dos fluxos conversacionais do chatbot, integração de APIs, serviços de backend e aplicação das diretrizes da LGPD no tratamento dos dados dos cidadãos.
WhatsApp Business API Chatbot LLM Node.js Python Docker Git

Kicker_IQ — Monitoramento e Desempenho Físico de Atletas

5DSM – 1º Sem. 2026

Sistema inteligente de apoio à tomada de decisão para comissões técnicas no futebol. Utiliza técnicas de machine learning para analisar grandes volumes de dados históricos e métricas físicas de jogadores, gerando relatórios de desempenho, predição de perfil e alertas preditivos.

Minha participação: Atuei no desenvolvimento Full Stack da aplicação: no frontend, realizei a integração do Design System (Figma), telas de Login e Importação e o módulo completo de Alertas com filtros dinâmicos e modais; no backend, desenvolvi a modelagem da entidade de Alertas em MongoDB com arquitetura Controller/Service e rotas CRUD autenticadas com JWT.
Next.js React TypeScript Tailwind CSS Node.js MongoDB JWT Python Machine Learning Docker
GitHub

VESTA — Detecção de Quedas para Idosos

4DSM – 2º Sem. 2025

Sistema inteligente de detecção de quedas para idosos, composto por dispositivo vestível conectado via Wi-Fi a um aplicativo mobile. O sistema identifica automaticamente quedas e envia alertas imediatos para cuidadores e familiares cadastrados.

Minha participação: Atuei como Product Owner do projeto, responsável pela definição de requisitos, priorização do backlog, coordenação da equipe de desenvolvimento e alinhamento das entregas em sprints com o cliente e stakeholders.
